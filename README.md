# Sistema de turnos - Consultorio Dr. Amado

Frontend con Next.js, React, TypeScript y shadcn/ui, conectado a las rutas reales del backend con sesiones por cookies.

Consultar [la guía de integración y el mapa del frontend](docs/frontend.md) para configurar Supabase, preparar usuarios, ejecutar la aplicación y encontrar el componente correspondiente a cada tarea.

```bash
npm install
npm run dev
```

Abrir http://localhost:3000/login.

```bash
npm run lint
npm run build
```
